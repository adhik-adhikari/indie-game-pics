About This Project

WEB103 Project 2 — Listicle Part 2

This web app is my submission for WEB103: Advanced Web Development at CodePath (Fall 2026). Project 2 upgrades the Project 1 listicle by replacing the static JavaScript data array with a real PostgreSQL database hosted on Render.

What Changed in Project 2

  • Data now lives in a PostgreSQL table on Render instead of a JS array
  • The backend exposes a JSON REST API (/api/games)
  • The frontend uses vanilla JS fetch() to retrieve and display data
  • HTML is built client-side by app.js and game.js
  • Added a live search feature (stretch goal)

Tech Stack

  • Backend: Node.js + Express
  • Database: PostgreSQL (hosted on Render)
  • DB Client: pg (node-postgres)
  • Frontend: Vanilla HTML + CSS + JavaScript (no framework)
  • Styling: PicoCSS v2 + custom CSS

The Data Schema

Each game in the games table has these columns:

  • id — auto-incrementing primary key
  • slug — unique URL-friendly identifier
  • title — game name
  • genre — type of game
  • developer — who made it
  • year — release year
  • platform — where you can play it
  • rating — score out of 10
  • description — full description
  • why_play — personal recommendation
  • image — cover art URL
